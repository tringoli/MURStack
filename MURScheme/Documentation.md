**MURScheme** — автономный веб-редактор схем скоростного и городского транспорта. Один HTML-файл, работающий прямо в браузере без сервера и зависимостей.

---

## 1. Запуск и архитектура

| Компонент     | Описание                                                                                                |
| ------------- | ------------------------------------------------------------------------------------------------------- |
| **Файл**      | `MURScheme.html` — единственный файл, всё внутри                                                        |
| **Запуск**    | Открыть в любом современном браузере (двойной клик)                                                     |
| **Стек**      | Vanilla JS + SVG + HTML/CSS. Никаких сборок, npm, Webpack                                               |
| **Хранилище** | `STATE` — единый объект состояния; `HISTORY` — стек undo/redo; `I18N` — локализация                     |
| **Рендер**    | Функции `render*()` перерисовывают SVG-слои по изменению `STATE`; `refreshCanvas()` — полный перерендер |

Состояние **не сохраняется автоматически**. Для сохранения используйте `💾 Проект → Скачать .json`.

---

## 2. Интерфейс

### Верхняя панель (header)
- **↩️/↪️** — Undo/Redo (`Ctrl+Z` / `Ctrl+Y`)
- **Сетка** — шаг сетки в px (по умолчанию 24)
- **Угол** — фиксация угла при трассировке (0°=свободно, 45°=классика)
- **Тип объекта** — `Линия ОТ` или декоративные (ЖД, дорога, граница, тонкая линия)
- **🗑️ Очистить всё** — сброс всей схемы
- **💾 Проект** — сохранение/загрузка `.json`
- **📥 Скачать** — экспорт в PNG/WEBP/JPG/JXL/SVG с выбором кадра и качества
- **🌐 Язык** — RU/EN + загрузка своего `.json`-перевода

### Левая панель инструментов
| Кнопка | Горячая клавиша | Назначение |
|---|---|---|
| 👆 | `V` | Выбор и панорамирование |
| 🚇 | `L` | Трассировка линии ОТ |
| ⚪ | `S` | Постановка остановки |
| ⇄ | `X` | Создание пересадки (клик по 2 станциям) |
| 🛤️ | `D` | Декоративный путь (ЖД, дорога…) |
| 🖌️ | `B` | Окрашивание местности |
| 📝 | `T` | Текстовая надпись |
| 📍 | `I` | Объект/иконка/POI |

### Правая панель управления
Аккордеоны со свойствами. Каждый можно **закрепить** (📌) — он поднимется наверх и останется видимым. Кнопки «Развернуть все» / «Свернуть все» — массовое управление.

### Нижний статус-бар
`X/Y` курсора · координата клетки · текущий режим · контекстная подсказка.

## 3. Основные объекты

### Линии (`STATE.lines[]`)
```js
{ id, name, subname, i18n, color, width, offset,
  dashStyle,        // solid | hollow | rail-dashed | rail-ties | double | express | dashed | dotted | cased
  points: [{x,y}, …],
  branches: [[{x,y}, …], …],  // подветки (ответвления)
  arrows: 'none'|'forward'|'backward'|'both'|'manual',
  arrowSegments: {'pathIdx:segIdx': 'forward'|…},  // по нодам
  manualArrows: [{pathIndex, segIndex, t, dir}],
  showBadgesAlong, badgesStyle, badgesSide, badgesInterval, …
}
```
- **Смещение в пучке** (`offset`) — сдвиг линии в параллельном коридоре.
- **Стрелки направления** — по всей линии или по выбранным участкам между нодами (клик по 2 нодам на карте).
- **Номера вдоль линии** — бейджи (круг, квадрат, «капля», петля и др.) с настройкой цвета/стороны/интервала.

### Остановки (`STATE.stations[]`)
```js
{ id, name, subname, i18n, x, y,
  style: 'metro-tick'|'smooth-ladder'|'cross-tick'|'interchange'|'capsule'|…,
  colorMode: 'line'|'stripes'|'white'|'black'|'custom',
  tickShift: 'auto'|'stagger'|'opposite',
  labelPos, labelAngle,
  lineIds: […],      // к каким линиям привязана
  showBadges, badgeShape, badgePos, badgeSize
}
```
- Привязываются к ближайшим линиям автоматически (`getLinesAtStation()`).
- Если на конце линии — превращаются в **конечный терминал** (см. ниже).

### Пересадки (`STATE.transfers[]`)
```js
{ id, stationIds: [id1, id2, …],
  style: 'radial-arc'|'radial-arc-walls'|'circle-hub'|'dumbbell'|'dotted'|'stadium-capsule',
  curvature,
  dashLength, dashGap, dashWidth, dashColor  // только для dotted
}
```
Цвет градиента автоматически берётся из цвета линий на соединяемых станциях.

### Декоративные пути (`STATE.decorations[]`)
```js
{ id, name, type: 'highway'|'rail'|'boundary'|'thin-line',
  color, width,
  showLabel, labelText, sublabelText,
  labelSide: 'center'|'above'|'below',
  repeatLabel, labelInterval,
  crossingMode: 'bridge'|'junction',
  points: [{x,y}, …]
}
```
- **`junction`** — бесшовные перекрёстки: внешние бордюры рисуются под внутренними полотнами, стыки не видны.
- Кнопка **«🔀 Создать бесшовные перекрёстки»** автоматически находит пересечения и вставляет туда вершины.

### Терминалы (`STATE.terminals[]`)
Конечные узлы — создаются:
1. **Автоматически** (`autoGenerate: true`) на концах линий.
2. **Вручную** кнопкой «+ Терминал» и кликом на карте.

```js
{ id, x, y, name, subname, lineIds,
  attach: 'track-exact'|'track-butt'|'line-end'|'on-line'|'offset',
  align: 'horizontal'|'vertical',
  badgeStyle, badgeSize, borderMode, bgMode, overlapMode
}
```
`overlapMode` при совпадении с остановкой: `badges-only` (только бейджи), `both` (бейджи + засечка), `hide-terminal`, `replace-station` (терминал вместо станции).

### Местность
- **`STATE.terrainLayers[]`** — слои с клетками `{ 'gx,gy': color }`.
- **`STATE.terrainLabels[]`** — текстовые надписи и POI-объекты (эмодзи, картинка с диска, векторный пин).
- Кисть: круглая, карандаш (1 клетка), заливка (bucket fill), ластик.
- Стиль `smooth-metaball` (SVG-фильтр) сглаживает береговые линии.

### Легенда (`STATE.legend`)
Настраиваемая карточка:
- Заголовок/подзаголовок, логотип (эмодзи/картинка), поворот.
- 1/2/3 колонки, авто-высота, ширина.
- Порядок маршрутов (▲▼), дополнительные пункты (`notes`).
- Быстрые шаблоны: **Муроморск**, **Магистраль**, **Табличный**.

## 4. Пучки маршрутов

- **Авто-сортировка** (`⚡ Сформировать пучки`): по номеру, алфавиту, цвету, числу остановок.
- **Межпутевой зазор** (`bundle-gap-input`) — отступ между линиями.
- **Синхронизация траекторий** (`⚡ Синхронизировать траектории пучка`) — уплотняет узлы «дочерних» линий по главной (по количеству точек 1–10).
- **Ручная группировка** — отметить чекбоксами нужные линии и нажать «Сгруппировать выбранные».

## 5. Экспорт

| Формат | Особенности |
|---|---|
| **PNG / WEBP / JPG / JXL** | Растеризация с выбором кадра (`screen` / `16:9` / `4:3` / `1:1` / `21:9` / свой) и множителя `1x–16x` |
| **SVG** | Векторный экспорт. Удаляются хэндлы, hitbox'ы, временные слои |
| **JSON** | Полный дамп `STATE` для последующей загрузки |

Шрифты встраиваются в растр через `getEmbeddedFontCss()` (base64 Google Fonts) — схема будет корректно отрендерена без интернета.

## 6. Обмен файлами

### 💾 Проект → `.json`
Полный дамп состояния. Загружается обратно через `📂 Загрузить .json` (с защитой от старых форматов — слияние `terminalsSettings` и `globalStyles`).

### 🔗 Поделиться
При клике предлагается выбор:

1. **Автономный HTML** — скачивается `MURScheme_view.html` со встроенным `window.__MURSCHEME_PRELOADED__` и всей схемой. Открывается **без интернета и без MURScheme**, в режиме просмотра.
2. **Онлайн-ссылка** — `#data=<base64-json>` в URL. Работает, только если получатель откроет её в MURScheme.

### Режим Read-Only
Автоматически активируется при загрузке из ссылки/автономного файла: скрывается тулбар, блокируются поля панели, добавляется класс `body.read-only-mode`.

## 8. Отладка

Кнопка **🐞 Логи** внизу холста открывает консоль:
- `🧪 Тест DOM` — проверка наличия всех ключевых элементов.
- `🔍 Дамп STATE` — вывод текущего состояния.
- `⚡ Тест рендера` — принудительный перерендер.
- `💥 Ошибка` — проверка перехватчика.
- Копирование / очистка логов.

Все ошибки (`window.onerror`, `unhandledrejection`) перехватываются и выводятся в консоль с подсветкой. Перехватчик в начале `<body>` ловит синтаксические ошибки ещё до старта.

## 9. Локализация (I18N)

- Базовые языки: **RU** (основной) и **EN**.
- Ключи — **русские строки** (`'Линии и маршруты'`), значения — переводы.
- Атрибуты `data-i18n`, `data-i18n-tooltip`, `placeholder`, `title` переводятся автоматически.
- Автообход текстовых узлов в `header`, `.sidebar-right`, `.status-bar`.
- **Своя локаль** — загрузить `.json` вида:
```json
{
  "lang": "de",
  "name": "Deutsch",
  "strings": {
    "Линии и маршруты": "Linien und Routen",
    "Остановки и станции": "Haltestellen und Bahnhöfe"
  }
}
```
Пустые ключи автоматически берутся из `en`, затем из `ru`.

- Карта: если у объекта задан `i18n.en`, при переключении на EN подпись меняется (для авто-сгенерированных остановок и линий это делается через `getMapElementLabels()`).

## 10. Расширения и точки входа

- **Новый инструмент** — добавить в `setTool()` + обработчики в `viewport.mousedown/mousemove/mouseup`.
- **Новый слой SVG** — добавить `<g id="my-layer">` в `#world-layer` и вызвать его `render*()` в `refreshCanvas()`.
- **Новый стиль линии** — добавить ветку в `renderLines()` (`if (style === 'my-style') …`).
- **Новый экспорт** — расширить `exportCleanRaster()` / `exportSvg()`.

---

## 11. Ограничения и нюансы

- Все объекты хранятся в памяти в `STATE`; автосохранения нет — регулярно жмите «Скачать .json».
- `HISTORY` ограничен 40 шагами (старые вытесняются).
- При больших схемах (сотни станций) SVG-рендер может тормозить — помогает отключение теней и сглаживания местности.
- В режиме Read-Only свойства недоступны, но навигация и зум работают.
- Массовая авто-расстановка остановок работает только для **активной** линии.

## 12. Быстрый старт

1. Открыть `MURScheme.html` в браузере.
2. Нажать **+ Линия** (или `L`) → клик по сетке для рисования трассы → `Enter` для завершения.
3. Инструментом **⚪** поставить остановки на линии.
4. Инструментом **⇄** кликнуть по 2 станциям — создастся пересадка.
5. Добавить декорации (**🛤️**), местность (**🖌️**) и легенду.
6. **💾 Проект → Скачать .json** для сохранения.
7. **📥 Скачать** или **🔗 Поделиться** — для публикации.

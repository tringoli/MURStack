# MURMaps — Локальный запуск (Windows / Linux / macOS)

Интерактивный 3D-навигатор и редактор карты Муроморска.

## Требования

- **Node.js 18+** (рекомендуется 20 LTS, 22 LTS или 24) и **npm**

## Быстрый старт локально

### Windows
1. Дважды нажмите на `start-windows.bat` (или запустите из PowerShell / CMD):
   ```bat
   start-windows.bat
   ```

### macOS
1. Дважды нажмите на `start-macos.command` в Finder (или запустите в Терминале `./start-linux-mac.sh`):
   ```bash
   chmod +x start-macos.command start-linux-mac.sh
   ./start-macos.command
   ```

### Linux
1. Дайте права на запуск (один раз) и запустите:
   ```bash
   chmod +x start-linux-mac.sh
   ./start-linux-mac.sh
   ```

### Универсальный запуск через npm (любая ОС)
```bash
npm install
npm run build
npm run local
```

Скрипт `start-local.mjs`:
- если папка `dist/` уже собрана (`npm run build`), запускает готовый портативный JS-сервер (`dist/server.mjs`) напрямую через Node.js — без `esbuild`, `tsx` и привязки к ОС (архив, собранный на Linux/macOS, мгновенно запускается на Windows);
- при отсутствии сборки или несовпадении бинарников другой ОС автоматически переустанавливает зависимости под текущую систему и собирает `dist/`;
- находит свободный порт (по умолчанию `3000`, можно задать через `PORT=3005`) и открывает `http://localhost:3000` в браузере;
- полезные флаги: `--dev` (режим разработки Vite), `--build` (пересобрать `dist/`), `--reinstall` (переустановить `node_modules`), `--no-open` (не открывать браузер).

## Загрузка и хранение сохранений карты

- Папка `data/` изначально пуста — предзагруженная схема не вшита.
- Чтобы загрузить свою схему, нажмите **«Загрузить сохранение (.json)»** в боковой панели слева (или **«Импорт»** в Редакторе карты) и выберите `.json`-файл сохранения.
- Изменения, внесённые в редакторе, и загруженные сохранения автоматически сохраняются локально в файл `data/murs-edits.json` на вашем компьютере.
- Кнопка **«Сохранить»** позволяет выгрузить текущее состояние карты в файл `murmaps-edits.json`.
